# Vĩnh XD – WordPress plugins & theme

Bộ plugin và theme WordPress của [Vĩnh XD](https://vinhxd.com).

| Thư mục | Tên | Phiên bản |
|---|---|---|
| `elementor-xd/` | Elementor XD | 1.0.0 |
| `popup-xd/` | Popup XD | 1.3.0 |
| `vinhxd-ga4/` | XD Analytics (GA4) | 1.14.1 |
| `xd-extra/` | XD Extra | 3.3.0 |
| `xd-mega-menu/` | XD Mega Menu | 3.3 |
| `theme-xd/` | Theme XD | v15 |

Cài đặt: nén thư mục tương ứng thành `.zip` rồi tải lên WordPress (Plugins → Add New → Upload, hoặc Appearance → Themes với theme).
